# Karaoke!
## A simple tool for lyrics managing

This is a simple script intended to run on top of any music player or server that uses .lrc files for lyrics.

It is, for now, a WIP, and **not usable in any state**, and in a very unclear future it may allow to also manage songs, directories and metadata, as a catalog manager, but that is uncertain.

Instructions on how to run and install will be here once the code is usable.
